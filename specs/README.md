# Specs

User-facing behavior of the app. Each file owns one aspect of what the player experiences. Architectural "how" lives in `../design/`.

| Spec | Scope |
|---|---|
| [puzzle-experience.md](puzzle-experience.md) | Solving a single puzzle end-to-end |
| [puzzle-map.md](puzzle-map.md) | The war-room HUD home screen: hero rating, stat tiles, five theme panels, PLAY button |
| [progression.md](progression.md) | Rating, mastery, review-queue evolution |
| [hints-and-analyze.md](hints-and-analyze.md) | No-hint solving policy; post-puzzle analyze mode |
| [scoring.md](scoring.md) | What "interesting" means and how puzzles are chosen |
| [data-model.md](data-model.md) | User-visible entities: puzzle, theme, player, session |
| [offline-and-privacy.md](offline-and-privacy.md) | Fully offline, no telemetry, no accounts |
| [accessibility.md](accessibility.md) | Baseline a11y: contrast, screen reader, motion, input |
